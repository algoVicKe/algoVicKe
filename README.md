# AI Engineering

<img src="https://img.shields.io/badge/-FROM%20MODEL%20TO%20PRODUCTION-B8973E?style=flat-square" alt="From model to production">

<br><br>

This repository covers the practical implementation of artificial intelligence<br>
as a complete engineering discipline. It looks beyond building models to how they are<br>
secured, deployed, and maintained.

<br>

</div>

---

## Scope

### 1. Artificial Intelligence

Computer vision, deep learning, natural language processing, statistical learning, and feature engineering.

**Depth:** the full AI lifecycle, from data preparation and training to evaluation and reproducibility.

<br>

### 2. Security

Threat modelling, secure design, the OWASP Top 10, input validation, supply chain risk, and monitoring.

**Depth:** security is applied at every stage, from requirements to operations, including the risks specific to AI systems.

<br>

### 3. DevOps

Containers, Kubernetes, CI/CD, GitOps, Helm, and Terraform.

**Depth:** automated delivery and defined reliability targets (SLIs, SLOs, and SLAs), so that a model in production is run as a service.

<br>

### 4. Software Engineering

Requirements, architecture, design, construction, testing, maintenance, version control, and documentation.

**Depth:** structured practice based on the Software Engineering Body of Knowledge (SWEBOK).

<br>

---

## Approach

Work is broken into clear steps and carried through to completion. Each project is documented, reproducible, and designed with security in mind from the start.
